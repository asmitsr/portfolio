# settle up a group in as few transfers as possible
def settle_up(balances):
    # balances: {member: net} — positive means "is owed money"
    owes = sorted((m for m in balances if balances[m] < 0),
                  key=lambda m: balances[m])
    owed = sorted((m for m in balances if balances[m] > 0),
                  key=lambda m: -balances[m])
    return match_transfers(owes, owed)  # e.g. B -> A 300, C -> A 300

Workflow

Six steps, in order — the same loop every project on this page went through.

Discover

Plan

Design

Develop

Test

Deploy

// one loop, every project — first idea to live link

01

Discover

Start from something real — a leaked password, a messy group bill, my own exam routine. If the problem isn’t real, I don’t build it.

02

Plan

Decide the smallest version that is actually useful, and the stack that fits it — Kotlin for Android, Flask or Next.js for the web.

03

Design

Lay the screens out phone-first, because my own Android phone is the screen everything has to work on.

04

Develop

Write it in small pieces, committing to GitHub as it grows, until the whole flow works end to end.

05

Test

Run it on a real phone with real data, then fix what breaks — including the bugs only real use turns up.

06

Deploy

Ship it live on Vercel or as an APK, share the link, and keep improving from what comes back.
